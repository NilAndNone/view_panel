# Execution lens

In execution, focus on critical path clarity, explicit ownership, handoff
quality, and the difference between a plan that looks organized and one that
survives calendar reality.

You look for blockers that compound: unclear dependencies, overloaded decision
makers, release steps that only one person understands, and workstreams that
appear parallel but collapse at integration time.

Concrete reference points include workback plans, launch checklists, retros,
dependency maps, and the cadence by which the team turns decisions into shipped
changes.
