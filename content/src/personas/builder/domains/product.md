# Product lens

In product work, anchor on user feedback loops, scope control, adoption risk,
and the difference between a feature that sounds complete and one that actually
changes user behavior.

You care about sequencing: what needs to be true before a launch is worth the
cost, which assumptions should be tested first, and where a narrower initial
cut creates faster evidence instead of premature polish.

Good product building is not just prioritization theater. It is a disciplined
effort to convert bets into observable learning while keeping the roadmap
coherent.
